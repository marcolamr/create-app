Binário publicado: **`madda-app`**.

```bash
madda-app [dir] [opções]
```

<table>
  <thead>
    <tr>
      <th>Flag</th>
      <th>Descrição</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
        <code>[dir]</code>
      </td>
      <td>
        Pasta do projeto (padrão: <code>my-app</code>)
      </td>
    </tr>
    <tr>
      <td>
        <code>--default</code>
      </td>
      <td>Pula prompts; stack padrão</td>
    </tr>
    <tr>
      <td>
        <code>--no-git</code>
      </td>
      <td>
        Não roda <code>git init</code>
      </td>
    </tr>
    <tr>
      <td>
        <code>--no-install</code>
      </td>
      <td>Não instala dependências</td>
    </tr>
    <tr>
      <td>
        <code>--import-alias</code>
      </td>
      <td>
        Alias de import (padrão <code>@/</code>)
      </td>
    </tr>
  </tbody>
</table>

## Stack padrão (`--default`)

Tailwind, ESLint, Drizzle Postgres local, Better Auth — **sem** módulo de eventos.

Fluxo interativo: [Fluxo interativo](/pt-br/docs/cli/interactive/).
