Só é gerado **com banco** selecionado.

```
src/server/auth/
├── config.ts
├── default-user-features.ts
├── client.ts / server.ts / index.ts
└── plugins/
```

`default-user-features.ts` define flags padrão para usuários novos (`create:session`, etc.).
