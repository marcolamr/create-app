---
title: Interactive flow
description: What the CLI asks when stdin is a TTY.
---

When you run without `--default` in a terminal, the CLI walks through:

1. **Project name**
2. **Tailwind CSS?**
3. **ESLint + Prettier?**
4. **Database (Drizzle)?** — None · PostgreSQL (Docker) · Neon
5. **Better Auth?** — only if a database was chosen
6. **Include events?** — only if Better Auth + database (firewall / rate-limit)
7. **Initialize git?**
8. **Run install?**

## Rules that matter

<table>
  <thead>
    <tr>
      <th>Choice</th>
      <th>Effect</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>No database</td>
      <td>Auth and events are <strong>not</strong> offered</td>
    </tr>
    <tr>
      <td>Auth without events</td>
      <td>Standard Better Auth + Drizzle schema</td>
    </tr>
    <tr>
      <td>Auth + events</td>
      <td>Adds <code>events</code> table, repositories, SQL scripts, <code>db:sql</code> scripts</td>
    </tr>
  </tbody>
</table>

Non-interactive environments (CI without TTY) get a **minimal** stack unless you pass `--default`.
