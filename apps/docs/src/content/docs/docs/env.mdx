---
title: Environment variables
description: Common env vars in generated projects.
---

Validation lives in `src/env.js` using `@t3-oss/env-nextjs` and Zod.

## Always (webserver block)

```ini
NEXT_PUBLIC_WEBSERVER_HOST=localhost
NEXT_PUBLIC_WEBSERVER_PORT=3000
```

## With Drizzle

```ini
DATABASE_URL=postgresql://...
```

Neon URLs include `?sslmode=require`.

## With Better Auth + DB

```ini
APP_NAME=my-app
BETTER_AUTH_SECRET=           # generated locally by CLI
BETTER_AUTH_URL=http://localhost:3000
BETTER_BASE_PATH=/api/v1/auth
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
TRUSTED_ORIGINS=http://localhost:3000
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_BETTER_BASE_PATH=/api/v1/auth
```

## Logging (optional)

```ini
# LOG_LEVEL=warn
# AXIOM_DATASET=
# AXIOM_TOKEN=
```

See `.env.example` in your generated app — it is safe to commit; copy to `.env` for secrets.
