The published binary is **`madda-app`** (via `npx @madda/app`).

## Basic usage

```bash
madda-app [dir] [options]
```

<table>
  <thead>
    <tr>
      <th>Argument / flag</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>[dir]</code></td>
      <td>Project directory name (default: <code>my-app</code>)</td>
    </tr>
    <tr>
      <td><code>--default</code></td>
      <td>Skip prompts; use the default stack</td>
    </tr>
    <tr>
      <td><code>--no-git</code></td>
      <td>Do not run <code>git init</code></td>
    </tr>
    <tr>
      <td><code>--no-install</code></td>
      <td>Skip package manager install</td>
    </tr>
    <tr>
      <td><code>--import-alias &lt;alias&gt;</code></td>
      <td>TypeScript import alias (default: <code>@/</code>)</td>
    </tr>
    <tr>
      <td><code>-v, --version</code></td>
      <td>Print CLI version</td>
    </tr>
    <tr>
      <td><code>-h, --help</code></td>
      <td>Show help</td>
    </tr>
  </tbody>
</table>

## Examples

```bash
# Current directory
pnpm create @madda/app . -- --default

# No git, no install (CI)
pnpm create @madda/app my-app -- --default --noGit --noInstall
```

## Default stack (`--default`)

- Tailwind CSS
- ESLint + Prettier
- Drizzle + local Postgres
- Better Auth
- **No** auth events / firewall module

For the interactive flow (conditional auth & events prompts), see [Interactive flow](/docs/cli/interactive/).
